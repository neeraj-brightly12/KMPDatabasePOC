## Overview

### The Flow in Simple Terms

```
1. Consumer App defines: Entities, DAOs, Database
2. KSP generates: DAO implementations, Database constructor
3. Consumer App creates: DatabaseFactory (using library)
4. Library builds: Configured Room database
5. Consumer App uses: Database to read/write data
```

### Key Players

| Component | Who Provides | Purpose |
|-----------|-------------|---------|
| **UserEntity** | Consumer (your app) | Data model |
| **UserDao** | Consumer (your app) | Interface for queries |
| **AppDatabase** | Consumer (your app) | Database definition |
| **DatabaseFactory** | Consumer (your app) | Concrete factory |
| **AndroidDatabaseFactory** | Library (kmp-room-core) | Abstract base class (Android) |
| **IosDatabaseFactory** | Library (kmp-room-core) | Abstract base class (iOS) |
| **DatabaseConfig** | Library (kmp-room-core) | Configuration data |
| **Room.databaseBuilder** | Room Library | Builds database |

```kotlin
import androidx.room.PrimaryKey
```

**What this does:**
- ✅ Defines table structure

## Step 2: Consumer Defines DAO

**File:** `app/src/commonMain/kotlin/com/myapp/data/dao/UserDao.kt`

```kotlin
package com.myapp.data.dao

import androidx.room.Dao
import androidx.room.Insert
import androidx.room.Query
import com.myapp.data.entity.UserEntity
import kotlinx.coroutines.flow.Flow

@Dao
interface UserDao {

    @Insert
    suspend fun insert(user: UserEntity)

    @Query("SELECT * FROM users")
    fun getAll(): Flow<List<UserEntity>>

    @Query("SELECT * FROM users WHERE id = :id")
    suspend fun getById(id: Int): UserEntity?

    @Query("DELETE FROM users WHERE id = :id")
    suspend fun delete(id: Int)
}
```

**What this does:**
- ✅ Defines database operations (CRUD)
- ✅ Room validates SQL at compile-time
- ✅ Returns Flow for reactive queries
- ✅ Uses suspend for coroutines

**Note:** This is an **interface** - no implementation yet!

## Step 3: Consumer Defines Database

**File:** `app/src/commonMain/kotlin/com/myapp/data/database/AppDatabase.kt`

```kotlin
package com.myapp.data.database

import androidx.room.ConstructedBy
import androidx.room.Database
import androidx.room.RoomDatabase
import androidx.room.RoomDatabaseConstructor
import com.myapp.data.dao.UserDao
import com.myapp.data.entity.UserEntity

@Database(
    entities = [UserEntity::class],
    version = 1,
    exportSchema = false
)
@ConstructedBy(AppDatabaseConstructor::class)
abstract class AppDatabase : RoomDatabase() {
    abstract fun userDao(): UserDao
}

@Suppress("NO_ACTUAL_FOR_EXPECT")
expect object AppDatabaseConstructor : RoomDatabaseConstructor<AppDatabase>
```

**Breaking this down:**

### @Database Annotation
```kotlin
@Database(
    entities = [UserEntity::class],  // ← Tables in this database
    version = 1,                     // ← Database version for migrations
    exportSchema = false             // ← Don't export schema JSON
)
```

### @ConstructedBy Annotation
```kotlin
@ConstructedBy(AppDatabaseConstructor::class)
```
- Tells Room to use `AppDatabaseConstructor` to create database
- KSP will generate the actual implementation

### expect/actual Pattern
```kotlin
expect object AppDatabaseConstructor : RoomDatabaseConstructor<AppDatabase>
```
- **expect:** Declaration in commonMain (no implementation)
- **actual:** Implementation generated by KSP for each platform

### Abstract Database Class
```kotlin
abstract class AppDatabase : RoomDatabase() {
    abstract fun userDao(): UserDao
}
```
- Extends Room's base class
- Abstract function to get DAO
- Room generates the implementation

## Step 5: Consumer Implements Android Factory

**File:** `app/src/androidMain/kotlin/com/myapp/data/database/DatabaseFactory.android.kt`

```kotlin
package com.myapp.data.database

import android.content.Context
import androidx.room.migration.Migration
import com.brightly.kmp.room.core.android.AndroidDatabaseFactory
import com.brightly.kmp.room.core.DatabaseConfig

actual class DatabaseFactory(
    context: Context
) : AndroidDatabaseFactory<AppDatabase>(context) {

    actual fun createDatabase(): AppDatabase {
        return createDatabase("app.db", emptyList())
    }

    override fun createDatabase(
        name: String,
        migrations: List<Migration>
    ): AppDatabase {
        return buildDatabase(

            DatabaseConfig(
                name = name,
                version = 1,
                enableLogging = true,
                migrations = migrations
            )
        )
    }

```

**Breaking this down:**

### Extends Library's Base Class
```kotlin

```
- Inherits from library's base factory
- Passes Android Context (needed for database creation)
- Generic type: `AppDatabase` (your database)

### Implements actual Function
```kotlin

    return createDatabase("app.db", emptyList())
}
```
- Implements the expect function from commonMain
- Calls overridden method with defaults
- Database name: "app.db"
- No migrations (empty list)

### Overrides Abstract Method
```kotlin
override fun createDatabase(
    name: String,
    migrations: List<Migration>
): AppDatabase
```
- Must implement this from `AndroidDatabaseFactory`
- Takes database name and migrations
- Returns configured database

### Calls Library's Method
```kotlin
return buildDatabase(
    AppDatabase::class.java,          // ← Your database class
    DatabaseConfig(                   // ← Configuration object
        name = name,                  // ← Database file name
        version = 1,                  // ← Database version
        enableLogging = true,         // ← SQL logging
        migrations = migrations       // ← Migration list

```
- `buildDatabase` is from `AndroidDatabaseFactory` (library)

## Step 7: Consumer Uses Database

**Android:**

```kotlin
// MainActivity.kt
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        // 1. Create database factory with Context
        val factory = DatabaseFactory(applicationContext)

        // 2. Create database
        val database = factory.createDatabase()

        // 3. Get DAO
        val userDao = database.userDao()

        // 4. Use DAO
        lifecycleScope.launch {
            // Insert
            userDao.insert(UserEntity(name = "John", email = "john@example.com"))

            // Query
            userDao.getAll().collect { users ->
                println("Users: $users")
            }
        }
    }
}
```

**iOS:**

```kotlin
// MainViewController.kt
fun MainViewController() = ComposeUIViewController {
    // 1. Create database factory (no Context needed)
    val factory = remember { DatabaseFactory() }

    // 2. Create database
    val database = remember { factory.createDatabase() }

    // 3. Get DAO
    val userDao = remember { database.userDao() }

    // 4. Use DAO
    LaunchedEffect(Unit) {
        userDao.insert(UserEntity(name = "Jane", email = "jane@example.com"))
    }
}
```

## KSP Generated: UserDao_Impl

**File:** `UserDao_Impl.kt`

```kotlin
package com.myapp.data.dao

import androidx.room.RoomDatabase
import androidx.sqlite.SQLiteStatement
import com.myapp.data.entity.UserEntity
import kotlinx.coroutines.flow.Flow
import kotlin.Int
import kotlin.String
import kotlin.Suppress
import kotlin.Unit

@Suppress("UNCHECKED_CAST")
internal class UserDao_Impl(
    private val database: RoomDatabase
) : UserDao {

    override suspend fun insert(user: UserEntity) {
        database.getQueryDispatcher().execute(true, false) { connection ->
            val statement: SQLiteStatement = connection.prepare(
                "INSERT INTO users (name, email) VALUES (?, ?)"
            )
            statement.bindText(1, user.name)
            statement.bindText(2, user.email)
            statement.step()
        }
    }

    override fun getAll(): Flow<List<UserEntity>> {
        val query = "SELECT * FROM users"
        return database.createFlow(
            tables = arrayOf("users"),
            isOneShot = false
        ) { connection ->
            val statement = connection.prepare(query)
            val list = mutableListOf<UserEntity>()

            while (statement.step()) {
                val id = statement.getInt(0)
                val name = statement.getText(1)
                val email = statement.getText(2)
                list.add(UserEntity(id, name, email))
            }
            list
        }
    }

    override suspend fun getById(id: Int): UserEntity? {
        return database.getQueryDispatcher().execute(true, false) { connection ->
            val statement = connection.prepare(
                "SELECT * FROM users WHERE id = ?"
            )
            statement.bindInt(1, id)

            if (statement.step()) {
                val userId = statement.getInt(0)
                val name = statement.getText(1)
                val email = statement.getText(2)
                UserEntity(userId, name, email)
            } else {
                null
            }
        }
    }

    override suspend fun delete(id: Int) {
        database.getQueryDispatcher().execute(true, false) { connection ->
            val statement = connection.prepare(
                "DELETE FROM users WHERE id = ?"
            )
            statement.bindInt(1, id)
            statement.step()
        }
    }
}
```

**What this does:**
- ✅ Implements the `UserDao` interface
- ✅ Converts Kotlin calls to SQL statements
- ✅ Binds parameters (prevents SQL injection)
- ✅ Maps SQL results to Kotlin objects
- ✅ Creates reactive Flow for queries

## Library: AndroidDatabaseFactory

**File:** `kmp-room-core/src/androidMain/kotlin/.../AndroidDatabaseFactory.kt`

```kotlin
package com.brightly.kmp.room.core.android

import android.content.Context
import androidx.room.Room
import androidx.room.RoomDatabase
import androidx.room.migration.Migration
import com.brightly.kmp.room.core.DatabaseConfig

abstract class AndroidDatabaseFactory<T : RoomDatabase>(
    protected val context: Context
) {
    /**
     * Builds Room database with configuration
     *
     * @param klass Database class (e.g., AppDatabase::class.java)
     * @param config Database configuration
     * @return Configured Room database instance
     */
    protected fun buildDatabase(
        klass: Class<T>,
        config: DatabaseConfig
    ): T {
        // Create Room database builder
        return Room.databaseBuilder(
            context,           // Android Context
            klass,            // Database class
            config.name       // Database file name
        ).apply {
            // Add migrations
            config.migrations.forEach { migration ->
                addMigrations(migration)
            }

            // Enable query logging if requested
            if (config.enableLogging) {
                setQueryCallback({ sqlQuery, bindArgs ->
                    println("SQL: $sqlQuery")
                    println("Args: $bindArgs")
                }, { it.run() })
            }
        }.build()
    }

    /**
     * Abstract method - consumer must implement
     * Should call buildDatabase with appropriate config
     */
    abstract fun createDatabase(
        name: String,
        migrations: List<Migration>
    ): T
}
```

**Method Breakdown:**

### buildDatabase() - Protected Method
```kotlin
protected fun buildDatabase(
    klass: Class<T>,
    config: DatabaseConfig
): T
```

**Purpose:** Builds configured Room database

**Parameters:**
- `klass`: Your database class (`AppDatabase::class.java`)
- `config`: Configuration object

**What it does:**

1. **Creates Room.databaseBuilder:**
```kotlin
Room.databaseBuilder(
    context,        // ← Android Context (passed in constructor)
    klass,          // ← Your database class
    config.name     // ← Database file name "app.db"
)
```

2. **Adds migrations:**
```kotlin
config.migrations.forEach { migration ->
    addMigrations(migration)
}
```
- If you provide migrations, adds them
- Room will apply when needed

3. **Enables logging:**
```kotlin
if (config.enableLogging) {
    setQueryCallback({ sqlQuery, bindArgs ->
        println("SQL: $sqlQuery")    // Logs SQL queries
        println("Args: $bindArgs")    // Logs parameters
    }, { it.run() })
}
```
- Only if `enableLogging = true`
- Prints all SQL queries to console
- Useful for debugging

4. **Builds database:**
```kotlin
.build()
```
- Finalizes configuration
- Returns Room database instance

### createDatabase() - Abstract Method
```kotlin
abstract fun createDatabase(
    name: String,
    migrations: List<Migration>
): T
```

**Purpose:** Must be implemented by consumer

**Consumer implements:**

## Library: IosDatabaseFactory

**File:** `kmp-room-core/src/iosMain/kotlin/.../IosDatabaseFactory.kt`

```kotlin
package com.brightly.kmp.room.core.ios

import androidx.room.Room
import androidx.room.RoomDatabase
import androidx.room.migration.Migration
import androidx.sqlite.driver.bundled.BundledSQLiteDriver
import com.brightly.kmp.room.core.DatabaseConfig
import platform.Foundation.NSHomeDirectory

abstract class IosDatabaseFactory<T : RoomDatabase> {

    /**
     * Builds Room database for iOS
     *
     * @param config Database configuration
     * @return Configured Room database instance
     */
    protected fun buildDatabase(config: DatabaseConfig): T {
        // Get iOS documents directory path
        val dbFile = NSHomeDirectory() + "/${config.name}"

        // Create Room database builder
        return Room.databaseBuilder<T>(
            name = dbFile,                    // Full path to database file
            factory = { getRoomDatabase() }   // Factory function
        ).apply {
            // Add migrations
            config.migrations.forEach { migration ->
                addMigrations(migration)
            }

            // Set SQLite driver (required for iOS)
            setDriver(BundledSQLiteDriver())
        }.build()
    }

    /**
     * Abstract method - consumer must implement
     */
    abstract fun createDatabase(
        name: String,
        migrations: List<Migration>
    ): T

    /**
     * Abstract method - must return database instance
     * This is called by Room's factory
     */
    protected abstract fun getRoomDatabase(): T
}
```

**Method Breakdown:**

### buildDatabase() - Protected Method
```kotlin
protected fun buildDatabase(config: DatabaseConfig): T
```

**Differences from Android:**

1. **Gets iOS path:**
```kotlin
val dbFile = NSHomeDirectory() + "/${config.name}"
```
- `NSHomeDirectory()` → iOS app's home directory
- Appends database name
- Result: `/path/to/app/container/app.db`

2. **Different builder signature:**
```kotlin
Room.databaseBuilder<T>(
    name = dbFile,                   // Full path (not just name)
    factory = { getRoomDatabase() }  // Factory lambda
)
```
- Takes full path (not Context + name)
- Requires factory function

3. **Sets driver:**
```kotlin
setDriver(BundledSQLiteDriver())
```
- iOS doesn't have built-in SQLite
- Uses bundled driver from dependency

### getRoomDatabase() - Abstract Method
```kotlin
protected abstract fun getRoomDatabase(): T
```

**Consumer implements:**
```kotlin
override fun getRoomDatabase(): AppDatabase {
    return Room.build<AppDatabase>()
}
```

### 2. DAO Implementation
```kotlin
// UserDao_Impl.kt (KSP generated)
override fun getAll(): Flow<List<UserEntity>> {
    val query = "SELECT * FROM users"
    return database.createFlow(
        tables = arrayOf("users"),      // Observe this table
        isOneShot = false               // Continuous observation
    ) { connection ->
        val statement = connection.prepare(query)
        val list = mutableListOf<UserEntity>()

        while (statement.step()) {
            val id = statement.getInt(0)
            val name = statement.getText(1)
            val email = statement.getText(2)
            list.add(UserEntity(id, name, email))
        }
        list
    }
}
```

**What happens:**
1. Creates reactive Flow
2. Observes "users" table
3. When table changes, re-executes query
4. Prepares SELECT statement
5. Iterates result rows
6. Maps each row to UserEntity
7. Returns list

### 3. Consumer Collects
```kotlin
.collect { users ->
    println("Users: $users")
}
```
- Receives list whenever data changes
- UI updates automatically
